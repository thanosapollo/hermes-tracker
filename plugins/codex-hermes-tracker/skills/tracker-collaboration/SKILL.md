# Tracker collaboration

Use `tracker_*` tools for durable work shared through Hermes Tracker.

- Tracker comments are public project history. Post conclusions, decisions, blockers, or verification evidence—not raw logs, secrets, hidden reasoning, heartbeats, private paths, or transient progress.
- Mutation identity comes from configured credentials and `HERMES_TRACKER_ACTOR`; never spoof another author.
- Read a TODO before mutating it. Preserve acceptance criteria and existing work.
- Create TODOs for durable project outcomes, not session notes.
- Claim only when taking responsibility for the outcome.
- Link TODOs only when the relationship materially affects understanding or execution.
- Close only after acceptance criteria pass. Record concise reproducible verification and a commit when available.
- Treat external execution references as provenance, not proof of completion. Never invent IDs or state.
